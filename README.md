# ArticleSphere

A Java-based article management system developed as a group project.

## 👨‍💻 Features:
- Article CRUD
- Admin/Non-admin login
- SQL Database integration

## 🛠️ Tech Used:
- Java
- JSP/Servlets
- MySQL
